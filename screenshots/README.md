# Screenshots

Bu dizin, WordPress eklentisi için ekran görüntülerini içerir.

WordPress.org'a yüklemek için ekran görüntüleri aşağıdaki şekilde adlandırılmalıdır:
- screenshot-1.png
- screenshot-2.png
- screenshot-3.png
- screenshot-4.png

## Gerekli Ekran Görüntüleri

### 1. screenshot-1.png - Ana Deprem Listesi Görünümü
- Shortcode ile gösterilen deprem listesi
- Renk kodlu büyüklükler
- Detaylı deprem bilgileri
- Yenile butonu

### 2. screenshot-2.png - Yönetim Paneli Ayarları
- Ayarlar → Deprem RSS sayfası
- Tüm ayar seçenekleri görünür
- RSS feed URL'si
- Önbellek ve otomatik yenileme ayarları

### 3. screenshot-3.png - Widget Görünümü
- Sidebar'da widget
- Widget başlığı
- Kompakt deprem listesi

### 4. screenshot-4.png - Responsive Mobil Görünüm
- Mobil cihazda görünüm
- Responsive tasarım

## Ekran Görüntüsü Oluşturma

Ekran görüntüleri oluşturmak için:

1. WordPress sitenizi kurun
2. Deprem RSS eklentisini yükleyin
3. Örnek içerik oluşturun
4. Tarayıcıda tam ekran yapın
5. Ekran görüntüsü alın (Print Screen)
6. 1200x900 piksel boyutuna göre düzenleyin
7. PNG formatında kaydedin

## Boyut Gereksinimleri

- **WordPress.org için**: 772x250 piksel (banner)
- **Ekran görüntüleri**: En az 1200 piksel genişliğinde PNG
- **Icon**: 256x256 piksel

## Notlar

- Gerçek deprem verileriyle ekran görüntüsü alın
- Türkçe arayüz görünür olsun
- Temiz ve profesyonel görünüm
- Tüm önemli özellikleri gösterin
